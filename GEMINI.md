# Правила для AI-агента Gemini CLI

Цей файл визначає основні правила та принципи роботи AI-агента в цьому проекті.

## 0. ⚠️ ПРАВИЛО МОДЕЛІ (КРИТИЧНО)

*   **ПРАЦЮЙ ВИКЛЮЧНО У FLASH-РЕЖИМІ.**
*   **ЗАБОРОНЕНО** викликати під-агентів або інструменти, що вимагають Pro-лімітів.
*   Якщо завдання занадто складне для Flash, просто розбий його на менші кроки.

## 1. Безпека та конфіденційність

*   **Золоте правило:** Ніколи не логуй, не коміть, не відображай та не передавай будь-яку секретну інформацію, ключі API, паролі, облікові дані або особисті дані користувачів. Це включає захист файлів `.env`, `.git` та конфігураційних директорій.

## 2. Якість коду та тестування

*   **Тестування – це закон:** Завжди додавай відповідні автоматизовані тести для будь-яких нових функцій або виправлень помилок. Зміни вважаються незавершеними без супровідної логіки верифікації.
*   **Дотримання стандартів:** Дотримуйся існуючих конвенцій кодування, архітектурних патернів та стилю проекту. Не використовуй "хаки" або обхідні шляхи, щоб уникнути попереджень лінтерів чи помилок компіляції.

## 3. Чітка комунікація та взаємодія з користувачем

*   **Прозорість дій:** Перед виконанням команд, що модифікують файли, систему, або потенційно можуть мати значний вплив (наприклад, `run_shell_command`), завжди надавай коротке, чітке пояснення мети команди та її потенційного впливу.
*   **Уточнення:** Якщо запит є неоднозначним або вимагає прийняття рішень, які виходять за межі чіткого розуміння, став уточнюючі запитання користувачеві.

## 4. Ефективний робочий процес

*   **Цикл розробки:** Завжди дотримуйся циклу: **Дослідження** (Research) -> **Стратегія** (Strategy) -> **Виконання** (Execution) -> **Валідація** (Validation).
*   **Мінімізація дій:** Прагни до мінімальної кількості кроків для досягнення мети, уникаючи зайвих операцій.

## 5. Правильне використання інструментів

*   **Атомність змін:** Уникай множинних одночасних редагувань одного й того самого файлу в рамках одного кроку. Розбивай складні зміни на менші, атомарні операції, перевіряючи стан файлу після кожної.
*   **Ефективність пошуку:** Використовуй інструменти пошуку (`grep_search`, `glob`) з максимально специфічними параметрами, щоб зменшити обсяг виводу та прискорити роботу.
