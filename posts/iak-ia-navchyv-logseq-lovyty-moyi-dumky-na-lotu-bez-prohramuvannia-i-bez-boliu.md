Я люблю Logseq. Серйозно. Це один з небагатьох інструментів, який реально змінив те, як я думаю і працюю. Граф знань, двосторонні посилання, щоденний журнал — все це працює саме так, як потрібно моєму голові сканера.
Але є одна проблема. Велика і незручна.
Logseq на телефоні — це біль.
Відкрити додаток, знайти потрібний журнал, натиснути в правильне місце, надрукувати думку поки вона ще є — і все це поки ти стоїш на автобусній зупинці або йдеш до магазину. До того часу як відкриється потрібний розділ, думка вже десь загубилась.
Я довго шукав рішення. Пробував різні застосунки для швидких нотаток, пробував Telegram собі, пробував просто голосові повідомлення. Нічого не приживалось — завжди був якийсь зайвий крок між "ідея з'явилась" і "ідея зафіксована".
А потім я подумав: а що як зібрати своє рішення? Я не програміст, але в мене є ШІ. І я вже налаштував купу всього в Logseq через AutoHotkey-скрипти — значить, ця задача мені до снаги.
Так з'явився мій голосовий інбокс.
---

Як це працює — просто і зрозуміло

Уявіть таку картину:
Ви йдете вулицею. Раптом приходить ідея — щось важливе, щось що не хочеться втрачати. Ви дістаєте телефон, натискаєте одну кнопку на екрані, кажете свою думку вголос. Телефон вібрує — все. Через кілька хвилин ідея вже сидить у вашому Logseq, акуратно підписана часом і тегом.
Ніяких застосунків. Ніяких підписок. Ніяких зайвих кроків.
Ось що відбувається "під капотом":
```
Ваш голос
    ↓
MacroDroid (телефон) — розпізнає мову
    ↓
Upstash Redis (хмара) — тимчасово зберігає
    ↓
Python скрипт (ноутбук) — забирає і записує
    ↓
Logseq — нотатка на місці

```
Кожна частина проста. Разом вони роблять щось справді корисне.
---

Що вам знадобиться

Перед тим як починати, переконайтесь що у вас є:
- Телефон Android (система працює саме на Android)
- Додаток MacroDroid — безкоштовний, є в Play Store
- Ноутбук або ПК з Windows і встановленим Python
- Logseq на ноутбуці з папкою журналів
Реєстрація на сторонніх сервісах: один акаунт на Upstash (безкоштовно). Більше нічого.
Час на налаштування: приблизно година, якщо робити вперше і не поспішати.

Частина 1: Upstash — наш хмарний буфер


Навіщо взагалі Redis?

Можна було б передавати нотатки напряму на ноутбук. Але що якщо ноутбук вимкнений? Що якщо ви надиктували 10 ідей за день поки були в дорозі?
Redis — це база даних яка працює як чергу. Телефон кидає туди нотатки, ноутбук забирає коли з'являється. Нічого не губиться. Upstash надає цей сервіс безкоштовно — і безкоштовного ліміту вистачить з головою (500 000 запитів на місяць, а нам потрібно максимум 10 000).

Реєстрація і налаштування

1. Зайдіть на upstash.com і зареєструйтесь через Google або GitHub — буквально одна кнопка.
2. Натискайте Create Database.
3. Заповніть:
	- Назва: будь-яка, наприклад my-logseq-inbox
	- Тип: Redis
	- Регіон: eu-central-1 (найближчий до України)
4. Після створення бази знайдіть розділ REST API і збережіть два значення:
	- UPSTASH_REDIS_REST_URL — виглядає як https://назва-бази.upstash.io
	- UPSTASH_REDIS_REST_TOKEN — довгий рядок символів
Збережіть їх — вони знадобляться далі.

Частина 2: MacroDroid — навчаємо телефон слухати

MacroDroid — це додаток для автоматизації на Android. Він дозволяє створювати "макроси": якщо натиснути кнопку → виконати дії. Нам потрібно два макроси: один для голосових нотаток, інший для текстових (бо не завжди зручно говорити вголос).

Макрос 1: Голосова нотатка

Тригер (що запускає макрос):
- Тип: Кнопка-віджет
- Оберіть колір і іконку — наприклад жовту з мікрофоном
Дія 1 — Голосовий ввід:
- Дії MacroDroid → Голосовий ввід (Google)
- Поставте "Зберегти в змінну"
- Назва змінної: logseq
Дія 2 — HTTP-запит:
- Дії MacroDroid → HTTP-запит
- Метод: POST
- URL: https://ВАШ-URL.upstash.io/lpush/inbox
У вкладці Параметри заголовка запиту додайте два заголовки:
Назва
Значення
Authorization
Bearer ВАШ_ТОКЕН
Content-Type
application/json
У вкладці Тіло запиту:
- Тип вмісту: application/json
- Текст (вставляйте змінну через кнопку ...):
```
{"text": "{v=logseq}", "tag": "роздуми"}

```


⚠️ Важливо: Змінну {v=logseq} потрібно вставляти через кнопку ... біля поля, а не вручну. Інакше MacroDroid не підставить значення і передасть буквальний текст.
Дія 3 (опціонально):
- Вібрація — щоб відчути що нотатка відправлена

Макрос 2: Текстова нотатка

Скопіюйте перший макрос, але замість "Голосовий ввід" використайте "Введення тексту" — з'явиться поле для введення. Змініть тег в JSON:
```
{"text": "{v=logseq}", "tag": "роздуми"}

```
Для нотаток-ідей можна зробити ще один макрос де тег буде "ідея" — тоді в Logseq вони автоматично матимуть різні теги.

Тест

Запустіть макрос, надиктуйте щось. Зайдіть в Upstash → CLI і введіть:
```
LRANGE inbox 0 -1

```
Якщо бачите свій текст — все працює. Якщо ні — перевірте токен у заголовку Authorization (пробіл між "Bearer" і токеном є?).

Частина 3: Python скрипт — серце системи

Цей скрипт забирає нотатки з Redis і записує їх у потрібне місце в Logseq. Він вміє:
- Знаходити розділ "нотатки/роздуми" у вашому шаблоні дня
- Вставляти нотатку з часом і тегом у правильному форматі
- Працювати і вручну (на запит), і автоматично у фоні

Встановлення Python

Якщо Python ще не встановлений — завантажте з python.org. При встановленні поставте галочку "Add Python to PATH".
Перевірте встановлення в PowerShell:
```
python --version

```
Встановіть бібліотеку для запитів:
```
pip install requests

```

Сам скрипт

Створіть файл redis_to_logseq.py (наприклад в папці D:\scripts\) і вставте код:
```
import requests
import json
import os
import time
import sys
from datetime import datetime

# --- НАЛАШТУВАННЯ — змініть під себе ---
URL = "https://ВАШ-URL.upstash.io"
TOKEN = "ВАШ_ТОКЕН"
LOGSEQ_PATH = r"D:\Logseq folder\journals"  # шлях до папки журналів
MARKER = "### **📓 нотатки/роздуми**"       # маркер розділу у вашому шаблоні
INTERVAL = 300  # секунд між автоматичними перевірками (300 = 5 хвилин)
# ----------------------------------------

def format_date_filename(dt):
    """Формує назву файлу у форматі Logseq: Apr 13th, 2026"""
    day = dt.day
    if 11 <= day <= 13:
        suffix = "th"
    elif day % 10 == 1:
        suffix = "st"
    elif day % 10 == 2:
        suffix = "nd"
    elif day % 10 == 3:
        suffix = "rd"
    else:
        suffix = "th"
    return dt.strftime(f"%b {day}{suffix}, %Y")

def insert_into_notes_section(full_path, text, time_str, tag):
    """Вставляє нотатку в розділ нотаток у файлі Logseq"""
    with open(full_path, "r", encoding="utf-8") as f:
        lines = f.readlines()

    # Шукаємо маркер розділу
    marker_idx = -1
    for i, line in enumerate(lines):
        if MARKER in line:
            marker_idx = i
            break

    # Якщо маркер не знайдено — додаємо в кінець
    if marker_idx == -1:
        with open(full_path, "a", encoding="utf-8") as f:
            f.write(f"\n{MARKER}\n\t\t\t- **{time_str}**\n\t\t\t\t- {text} #{tag}\n")
        return

    # Визначаємо відступ автоматично
    base_indent = "\t\t\t"
    for j in range(marker_idx + 1, len(lines)):
        line = lines[j]
        if line.strip().startswith("-"):
            base_indent = line[:line.find("-")]
            break

    child_indent = base_indent + "\t"
    new_block = f"{base_indent}- **{time_str}**\n{child_indent}- {text} #{tag}\n"

    # Знаходимо місце вставки (кінець розділу)
    insert_at = len(lines)
    marker_line_indent = len(lines[marker_idx]) - len(lines[marker_idx].lstrip('\t '))

    for j in range(marker_idx + 1, len(lines)):
        line = lines[j]
        if not line.strip():
            continue
        current_indent = len(line) - len(line.lstrip('\t '))
        if line.lstrip().startswith("#") or (line.lstrip().startswith("-") and current_indent <= marker_line_indent):
            insert_at = j
            break

    if insert_at == len(lines) and len(lines) > 0:
        if not lines[-1].endswith("\n"):
            lines[-1] += "\n"

    lines.insert(insert_at, new_block)

    with open(full_path, "w", encoding="utf-8") as f:
        f.writelines(lines)

def process_inbox():
    """Забирає всі нотатки з Redis і записує в Logseq"""
    endpoint = f"{URL}/rpop/inbox"
    headers = {"Authorization": f"Bearer {TOKEN}"}

    while True:
        try:
            response = requests.post(endpoint, headers=headers)
            if response.status_code != 200:
                break

            result = response.json().get("result")
            if not result:
                break

            try:
                data = json.loads(result)
                text = data.get("text", result).strip()
                tag = data.get("tag", "роздуми")
                note_time = data.get("time", datetime.now().strftime("%H:%M"))
            except:
                text = result.strip()
                tag = "роздуми"
                note_time = datetime.now().strftime("%H:%M")

            file_name = format_date_filename(datetime.now()) + ".md"
            full_path = os.path.join(LOGSEQ_PATH, file_name)

            if os.path.exists(full_path):
                insert_into_notes_section(full_path, text, note_time, tag)
            else:
                with open(full_path, "w", encoding="utf-8") as f:
                    f.write(f"{MARKER}\n\t\t\t- **{note_time}**\n\t\t\t\t- {text} #{tag}\n")

            print(f"✅ Додано: {text} #{tag}")

        except Exception as e:
            print(f"❌ Помилка: {e}")
            break

if __name__ == "__main__":
    if "--daemon" in sys.argv:
        # Режим демона: перевіряє Redis кожні N секунд у фоні
        print(f"🚀 Демон запущено. Перевірка кожні {INTERVAL // 60} хвилин.")
        while True:
            process_inbox()
            time.sleep(INTERVAL)
    else:
        # Ручний режим: запустився, обробив, закрився
        print("⚡ Ручний запуск")
        process_inbox()

```

Як адаптувати під себе

В розділі НАЛАШТУВАННЯ змініть три речі:
URL і TOKEN — скопіюйте з Upstash.
LOGSEQ_PATH — шлях до папки journals вашого графу. Щоб знайти її: відкрийте будь-який журнальний день в Logseq, правою кнопкою → "Показати у провіднику".
MARKER — текст заголовка розділу у вашому шаблоні дня куди мають падати нотатки. Якщо у вас немає шаблону або розділ називається інакше — скрипт просто додасть нотатки в кінець файлу.

Частина 4: Запуск і автоматизація


Ручний запуск — .bat файл з шорткатом

Створіть файл logseq_manual.bat на робочому столі:
```
@echo off
chcp 65001
python "D:\scripts\redis_to_logseq.py"
pause

```
Потім зробіть ярлик на цей файл (правою кнопкою → Надіслати → Робочий стіл). На ярлику: Властивості → поле "Швидкий виклик" → натисніть наприклад I. Windows автоматично призначить Ctrl+Alt+I.
Тепер з будь-якого місця на комп'ютері Ctrl+Alt+I — і скрипт запускається, забирає всі нотатки з Redis і кладе в Logseq.

Автоматичний запуск при старті Windows

Щоб демон стартував автоматично разом з Windows:
1. Натисніть Win+R, введіть shell:startup, натисніть Enter
2. У папці що відкрилась: правою кнопкою → Створити → Ярлик
3. В полі об'єкта введіть:
```
pythonw "D:\scripts\redis_to_logseq.py" --daemon

```
4. Назвіть ярлик Logseq Daemon
pythonw запускає Python повністю у фоні — без жодного вікна.
Після перезавантаження демон стартує сам і перевіряє Redis кожні 5 хвилин. Навіть якщо забудете запустити вручну — нотатки все одно потраплять в Logseq.

Скільки запитів витрачається?

Кожні 5 хвилин = 288 запитів на добу = ~8 600 на місяць. Безкоштовний ліміт Upstash — 500 000 на місяць. Ми використовуємо менше 2% ліміту.

Як виглядає результат в Logseq

Після запуску скрипта у вашому щоденнику з'явиться:
```
📓 нотатки/роздуми
    - 14:32
        - Зателефонувати Василю щодо проекту #роздуми
    - 16:47
        - Ідея для нової статті про PKM для сканерів #ідея

```
Час — коли запустили скрипт (або можна передавати з телефону). Тег — залежно від того яку кнопку натиснули на телефоні.

Що далі можна додати

Система вже повністю працює, але є куди розвиватись:
Обробка ідей через Gemini CLI — окремий скрипт який бере нотатку з тегом #ідея, передає в Gemini і отримує назад структурований проект: назва, кроки, ресурси. Проект зберігається як окрема сторінка в Logseq з посиланням з щоденника.
Другий MacroDroid для ідей — окрема кнопка віджету з іншим кольором, яка відправляє "tag": "ідея". Тоді одним дотиком визначаєте чи це роздум чи ідея.
Текстовий режим — третій макрос з "Введення тексту" замість голосового вводу. Зручно коли не можна говорити вголос.

Чому це краще за готові рішення

Я пробував різні застосунки для capture на ходу. Всі вони мають одну спільну проблему: це окремий застосунок з окремою базою даних. Нотатки там і нотатки в Logseq — це два різних світи.
Те що я описав — це не окремий застосунок. Це пряма труба в Logseq. Нотатка падає саме туди де має бути, з правильним тегом, у правильний день, у правильний розділ.
І ще один момент який для мене важливий: нічого зайвого не стоїть між мною і моїми думками. Без підписок, без обмежень, без чужих серверів де зберігаються мої нотатки. Redis тільки тимчасово тримає дані поки ноутбук не забере їх — після цього в хмарі нічого не залишається.
